一、运行环境
  引擎：团结引擎 Tuanjie 2022.3.62f3c1（Unity 2022.3 LTS 同源）
  模板：2D (Built-In)，无额外插件依赖

二、如何打开
  1. Unity Hub → 打开 → 选择本文件夹（克隆后为 ElementResonance）
  2. 双击打开场景：Assets/Scenes/Game.unity
  3. 点击顶部 Play 按钮开始游戏

三、操作说明
  移动：WASD 或方向键（八方向）
  攻击：全自动（飞刀自动索敌，无需按键）
  升级：弹出三选一面板时，鼠标点击选择强化
  目标：存活到 6:00，击败 Boss 即胜利；死亡可点击"重新开始"

四、游戏内容速览
  · 4 种敌人（史莱姆/蝙蝠/坦克/精英）+ Boss（冲锋/弹幕/召唤三招）
  · 3 种武器（飞刀/旋刃/新星）+ 10 种强化 + 火/雷/冰三系元素共鸣
  · 4 段波次难度曲线，2:30 与 5:00 刷新精英
  · 胜利/失败结算，一键重开

  —— 项目由 3 天集中开发完成（按 10 阶段施工计划推进），设计文档见本仓库 docs 文件夹。
