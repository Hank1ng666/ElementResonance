### 1. 开始界面（新功能）

| 项 | 内容 |
|---|---|
| 文件 | `GameManager.cs` + 场景 Canvas 下新物体 `StartPanel` |
| 组成 | 半透明遮罩 + 标题"元素共鸣 / ELEMENT RESONANCE" + 操作说明（WASD移动，武器全自动，击败6:00的Boss获胜）+ Button"开始游戏" |
| GameManager 新增字段 | `Start Panel` ← 拖 StartPanel（**不填 = 保持点 Play 直接开局**，防御式兼容）；`Victory Stats Text` ← 胜利面板的战绩 Text |
| 新增方法 | `Start()`：检测到 startPanel 就 `SetActive(true)` + `timeScale=0` 暂停全场；`StartGame()`：关面板 + `timeScale=1` 开局（按钮 OnClick 绑定它） |
| 原理要点 | uGUI 事件走 unscaled 时间，`timeScale=0` 时按钮照样可点——所以用暂停而非 `state` 变量实现"等待开始"，不侵入原有状态机 |
| 维护注意 | StartPanel 的显示/隐藏归 GameManager 管；改按钮文案直接改 Button 下的 Text |

### 2. 飞刀朝向修复（视觉缺陷，历史遗留）

- 问题：飞刀自 Day 3 起以 `Quaternion.identity` 生成且从不旋转——竖直长条朝任意方向平移。
- 修复：`Projectile.Init()` 末尾加一行 `transform.up = dir;`（2D 标准瞄准：局部 Y 轴对准飞行方向；生成瞬间生效，扇形多刀各转各的）。
- 教训归档：排查时先怀疑"改开始按钮弄坏的"，git 历史证明**从未有过旋转代码**——"改了X之后Y坏了"要先验证"Y在改X之前正常吗"。

### 3. 雷共鸣误勾修复（数据事故）

- 场景文件烧入 `hasLightningResonance: 1`（Day 9 拖音频时误触勾选框 + 保存），导致开局自带连锁闪电、两次选雷之精华不再弹共鸣公告。
- 修复：Inspector 取消勾选（提交 e87163d）。
- 架构根因已记入 06 愿望单 D 类（运行时状态不该可序列化）。

## 音效接线总表（Day 9 加入，蓝图漏记，此处补全）

代码钩子已内置（全部判空，不拖 = 静音不报错）：

| AudioClip 字段 | 挂载对象 | 用途 |
|---|---|---|
| `hitClip` | Projectile_Dagger 预制体 | 命中敌人 |
| `pickupClip` | Pickup_Gem / Pickup_Heart 预制体 | 拾取 |
| `levelUpClip` / `resonanceClip` | 场景 Player（PlayerStats） | 升级 / 共鸣公告 |
| `appearClip` | Enemy_Boss 预制体 | Boss 登场 |
| `gameOverClip` / `victoryClip` | GameManager | 胜负结算 |
| （AudioSource 组件） | GameManager | BGM，Loop ✓，Volume≈0.4 |

音量纪律：`PlayClipAtPoint` 固定音量 1（Unity 上限即 1），嫌小/嫌大**换文件**或 Audacity ±6dB，不改代码。
