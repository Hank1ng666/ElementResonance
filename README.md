# 《元素共鸣》Element Resonance

> 3 天集中开发的 **2D 俯视角 Roguelite 生存游戏**（Vampire Survivors-like，按 10 阶段施工计划逐阶段推进验收）
> Unity 2022.3 (Tuanjie) · C# · 无插件依赖

在封闭场地中走位求生，武器全自动攻击；击杀获取经验、三选一强化构筑流派，
同元素强化叠加触发**元素共鸣**（燃烧 / 连锁闪电 / 减速）；撑过 10 分钟
难度曲线，在 6:00 迎战三招循环的 Boss，争夺结算。

## 核心系统

| 系统 | 说明 |
|---|---|
| 数据驱动配置表 | 波次表（4 段难度曲线）与强化池（10 条强化）均为 Inspector 可编辑的序列化数据，**加内容零代码** |
| 三种命中判定模型 | 飞刀（触发器配对 + 自动索敌）· 旋刃（环绕碰撞 + 单体限频）· 新星（`OverlapCircleAll` 范围询问） |
| 元素共鸣 | 火/雷/冰同元素累计选取触发，效果与 Boss 战联动 |
| Boss AI | 独立状态机（刻意不与小怪继承复用）：前摇闪红冲锋 / 环形弹幕 / 召唤 |
| 升级暂停流 | `timeScale` 冻结 → 三选一 → 效果应用 → 恢复，连升队列依次弹板 |
| 对象架构 | Prefab 化 + `Init()` 引用注入：运行时物体零场景依赖 |
| HUD / 结算 | 血条/经验/等级/计时/击杀/Boss 血条实时刷新，胜负面板一键重开（timeScale 恢复管理） |

## 如何运行

1. Unity Hub（2022.3 LTS 或团结引擎同版本）打开本工程
2. 打开场景 `Assets/Scenes/Game.unity`
3. 点击 Play

**操作**：WASD / 方向键移动，其余全自动；升级时鼠标点选强化。

## 数值调优（试玩驱动迭代）

三轮"实测 → 记录 → 单旋钮调整"：

1. 飞刀伤害 10→15、精英 400→300（修复开局输出 < 刷怪流量的消耗战死局）
2. 难度成长 0.4→0.6 / 0.15→0.25、末段刷怪间隔收紧（修复中后期无压力）
3. 终局怪潮配比加权快速怪（蝙蝠 40%→60%，威胁源聚焦）

详细证据与决策见 [05_意见箱](docs/05_平衡优化_意见箱.md)。
